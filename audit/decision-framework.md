# Decision Framework

Use this framework for project decisions.

## Step 1: Frame The Problem

- What outcome are we trying to create?
- What layer is affected?
- What state could be damaged?
- What are the constraints?

## Step 2: Generate Options

Include:

- conservative option,
- fast option,
- robust option,
- reversible option,
- experimental option.

## Step 3: Evaluate

Score options by:

- recoverability,
- privacy,
- correctness,
- effort,
- future flexibility,
- runtime risk,
- evidence quality.

## Step 4: Decide

Pick one and record:

- why,
- what evidence supports it,
- what would falsify it,
- rollback route.

## Step 5: Verify

Every decision that changes files or runtime state needs evidence after implementation.

## Step 6: Revisit

Set a review trigger for decisions with uncertainty.
