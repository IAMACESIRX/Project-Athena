# Task Routing Pipeline

## Pipeline

1. Goal submitted.
2. Executive review.
3. Project brain selection.
4. Reasoning council analysis.
5. Governance review.
6. Instruction generation.
7. Coordination assignment.
8. Model and tool routing.
9. Execution.
10. Observation audit.
11. Adaptive learning.
12. Knowledge storage.

## Routing Criteria

- Required capability.
- Risk level.
- Evidence availability.
- Model strengths.
- Tool access.
- Cost and latency.
- Trust score.
- Human priority.
