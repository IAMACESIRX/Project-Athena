# Real-Time Local Learning And Plasticity

Plasticity means the system can adapt locally as new evidence arrives.

## Allowed Adaptation

- update work items,
- update risk register,
- update module cards,
- add concept-bank entries,
- update playbooks after failures,
- improve diagnostic scripts.

## Guardrails

- Do not rewrite core policy casually.
- Do not promote assumptions to facts without evidence.
- Do not erase audit trails to make the system look cleaner.
- Do not let generated reports become unreviewed policy.

## Learning Loop

Observation -> interpretation -> work item or memory update -> verification -> audit event -> refined procedure.
