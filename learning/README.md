# Learning System

The learning system tracks how the project improves over time.

## Goals

- Learn from failures.
- Strengthen recurring concepts.
- Avoid rediscovering the same facts.
- Track model/tool limitations.
- Improve procedures after each incident.

## Main Areas

- `concept-bank/`: strengthened reusable concepts.
- `lessons-learned.md`: durable lessons.
- `plasticity-policy.md`: how learning changes behavior.
- `meta-learning.md`: how the system improves its own learning.
