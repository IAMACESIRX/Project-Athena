# F.O.R.G.E. Human–AI Pipeline Contract

F.O.R.G.E. conforms to the project-wide Human–AI Interoperable Pipeline Standard.

- Profile: `standards/human-ai-pipeline/profiles/forge.yml`
- Manual form: `standards/human-ai-pipeline/templates/manual-run-packet.md`
- Shared run tool: `tools/human_ai_pipeline.py`
- F.O.R.G.E. compiler: `forge/compiler/forge_compiler.py`

The shared run packet surrounds the F.O.R.G.E. concept packet and compiler trace. Human intervention, mitigation, benefit preservation, and process review remain available before and after deterministic compilation.
