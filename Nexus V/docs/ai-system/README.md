# Archived AI System Mirror

This folder is a retained historical mirror of the earlier AI-system layer that
was packaged into the Nexus V documentation set.

It is no longer the active Project Athena operating root. The active system is:

`D:\Projects\Project Athena`

Use the active root files first:

1. `AI-PORTAL.md`
2. `START-HERE.md`
3. `context.md`
4. `Plan/context.md`
5. `context-file-index.md`
6. `manifests/system-manifest.json`
7. `memory/athena-memory-map.md`
8. `tools/Invoke-AIOperationCycle.ps1`

## Archive Role

- Preserve lineage for the old local AI-OS control-plane layout.
- Provide source material for concepts that were later promoted into Project
  Athena.
- Keep old path names, schemas, and WoW-era assumptions available for forensic
  comparison.
- Avoid serving as the first-read operating guide for new Athena work.

Do not run scripts from this archive unless the task explicitly concerns legacy
reconstruction. Current automation lives in the root `tools/` folder.
