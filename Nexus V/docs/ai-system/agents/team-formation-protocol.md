# Team Formation Protocol

Use this protocol when a goal needs more than one agent or model.

## Steps

1. Parse the goal.
2. Identify domains.
3. Identify required capabilities.
4. Identify risk level.
5. Select project brain.
6. Select lead agent.
7. Select supporting agents.
8. Assign evidence and verification responsibilities.
9. Set consensus level.
10. Define handoff output.

## Default Teams

- Coding task: executive, codex engineer, governance, observer.
- Research task: executive, research agent, truth pipeline, semantic compression.
- Diagnostic task: observer, log intelligence, forensic verification, counterfactual reasoning.
- Strategy task: executive, board, council, risk, resource steward.
