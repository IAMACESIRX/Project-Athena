# Deep Counterfactual Protocol

## Questions

- What if this assumption is false?
- What if the opposite decision were made?
- What if the restore fails halfway?
- What if logs are misleading?
- What if the wrong repo/layer is changed?
- What if the disk fills during backup?
- What if an AI loses context mid-task?

## Output

For each counterfactual:

- scenario,
- likely effect,
- detection signal,
- mitigation,
- rollback.
