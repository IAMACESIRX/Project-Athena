# MCP And Tool Layer

This layer defines how external tools, MCP servers, plugins, scripts, and programs connect safely.

## Rules

- Tools must be registered before routine use.
- Tool output is evidence, not automatic truth.
- High-risk tool access requires governance review.
- File edits must preserve project ownership boundaries.
- Cloud tools are disabled for local-only projects unless the human changes policy.

## Tool Classes

- Filesystem tools.
- Shell tools.
- Git tools.
- Browser tools.
- Database tools.
- Model providers.
- Document and spreadsheet tools.
- Observability probes.
- Backup and restore tools.
