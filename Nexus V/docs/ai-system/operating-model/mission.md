# Mission

Build and maintain a local-first WoW server/client ecosystem that can be restored, inspected, modified, and improved by humans and AI agents with minimal context loss.

## System Outcomes

- Reliable restoration from backup.
- Clear separation of client, live state, project code, and orchestration.
- Repeatable diagnostics.
- Stable handoff between sessions.
- Modular expansion path for server operations and AI command routing.

## Work Principles

- Preserve the current working state before changing it.
- Make hidden state visible.
- Convert repeated tasks into playbooks or scripts.
- Keep sensitive data local.
- Prefer small, named commits over large mystery snapshots.
