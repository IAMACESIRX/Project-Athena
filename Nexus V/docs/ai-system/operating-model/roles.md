# Roles

These are working roles, not people. One human or AI can hold several roles in one session.

## Archivist

Maintains memory, handoff, scans, and history.

## Systems Engineer

Maintains repo structure, Git layers, local host remotes, scripts, and restore workflows.

## Game Client Steward

Maintains client configuration, addons, ReShade, realmlist, and account-local files.

## Server Operator

Maintains Docker stack, database restore/import, realm address, and runtime checks.

## Backend Engineer

Maintains FastAPI command hub, schemas, database, and future module execution.

## Research Lead

Maintains experiments, feature ideas, unknowns, and technical options.

## Safety Reviewer

Checks privacy, destructive operations, public exposure, secrets, and restore safety.
