# Algorithmic Inversion

Algorithmic inversion is thinking backward from a desired output, failure, or observed effect to the inputs, causes, constraints, and steps that could produce it.

## Use For

- debugging,
- restore planning,
- rollback planning,
- feature design,
- root cause analysis,
- test design.

## Core Rule

Backward reasoning creates candidate paths. Candidate paths must still be checked forward against evidence.
