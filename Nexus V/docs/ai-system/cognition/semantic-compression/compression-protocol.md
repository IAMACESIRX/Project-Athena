# Semantic Compression Protocol

## Preserve

- decisions,
- constraints,
- evidence,
- causality,
- rollback paths,
- unresolved risks,
- exact file paths,
- timestamps,
- actor/source.

## Compress

- repeated phrasing,
- low-value narration,
- duplicate command output,
- redundant context,
- resolved exploration details.

## Method

1. Identify source type.
2. Extract irreducible facts.
3. Extract decisions and causes.
4. Extract open risks.
5. Compress remaining context.
6. Label what was omitted.

## Output

```text
Source:
Compression ratio:
Preserved facts:
Preserved decisions:
Omitted low-value data:
Risk of loss:
Where stored:
```
