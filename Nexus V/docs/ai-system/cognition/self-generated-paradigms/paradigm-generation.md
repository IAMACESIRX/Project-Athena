# Paradigm Generation

## Process

1. Name the current paradigm.
2. Identify what it explains well.
3. Identify what it fails to explain.
4. Generate a new model.
5. Use the new model on one concrete problem.
6. Keep, revise, or discard.

## Example Paradigms

- project as organism,
- project as operating system,
- project as flight recorder,
- project as lab,
- project as layered nervous system,
- project as local-first sovereign infrastructure.

