# Process Plasticity

## Inputs

- failures,
- repeated tasks,
- stale docs,
- scan noise,
- user corrections,
- tool errors,
- successful workflows.

## Adaptation Types

- add a playbook,
- revise a protocol,
- create a tool,
- promote a concept to memory,
- demote stale context,
- tighten a governance rule,
- relax a noisy check.

## Safety Gates

- Update audit if process change matters.
- Keep old behavior recoverable if possible.
- Do not weaken absolutes without human direction.
- Verify new process with at least one run.
