# Cognition Workflow

## Flow

1. Frame the problem.
2. Choose cognition systems.
3. Generate candidates.
4. Label evidence status.
5. Cross-check through `truth/`.
6. Record useful outputs.
7. Convert action-worthy outputs into work items, experiments, or decisions.

## Selection Guide

- Hidden intent or implication: subtext.
- Patterns and cause/effect: correlation.
- Team alignment: collaborative group dynamics.
- Unsupported claims: anti-hallucination.
- Bold idea: conceptual leap.
- New model: self-generated paradigm.
- Weird but useful possibility: counter-intuitive discernment.
- Assumption attack: Socratic deconstruction.
- Stale approach: non-linear disruption.
- New feature/system: original creation.
- Process adaptation: dynamic process plasticity.
- Many shifting signals: liquid-state machine.
- Desired outcome or observed effect: algorithmic inversion.
- Long context reduction: semantic compression.
- Partial truth or conflicting evidence: multi-valued fuzzy logic.
- Meaning drift: semantic drift self-correction.
- Multiple live interpretations: superposition non-binary.
- Later outcome to earlier cause: retrocausal processing.
- Revisable default conclusion: non-monotonic reasoning.
- Stable orientation across context loss: contextual anchoring.
- Many-way dependencies: hypergraph relational processing.
