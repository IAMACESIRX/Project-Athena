# Superposition Protocol

## Use When

- multiple explanations fit evidence,
- user intent could mean several things,
- runtime state is unknown,
- a decision has competing valid paths,
- forcing a binary choice would hide risk.

## Method

1. List possible states.
2. Assign evidence and confidence to each.
3. Define collapse conditions.
4. Keep safe actions that work across states.
5. Avoid risky actions until state collapses.
