# Question Bank

## Project Questions

- What layer owns this?
- Is this live runtime or backup state?
- Is this a fact, inference, or preference?
- What would make this dangerous?
- What does success look like?

## Debugging Questions

- When did it last work?
- What changed since then?
- What evidence points to the cause?
- What else could explain the same symptom?
- What is the least invasive test?

## Design Questions

- What should be modular?
- What should be stable?
- What should be generated?
- What should require human confirmation?
- What should be reversible?
