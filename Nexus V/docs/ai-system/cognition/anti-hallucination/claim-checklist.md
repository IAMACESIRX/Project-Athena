# Claim Checklist

Before making a claim, classify it.

## Claim Type

- file state,
- Git state,
- runtime state,
- user intent,
- project history,
- causality,
- future risk,
- recommendation.

## Evidence

- command output,
- file content,
- generated scan,
- human instruction,
- inference only.

## Confidence

- verified,
- likely,
- inferred,
- speculative,
- unknown.

## Action

- safe to act,
- ask user,
- run verification,
- record as hypothesis.
