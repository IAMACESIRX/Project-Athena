# User And Team Context

## Collaboration Style

- The human wants a powerful, persistent project system rather than one-off fixes.
- The system should help future humans and AIs avoid repeating discovery work.
- The project should support advanced diagnostics, R&D, engineering management, and hands-on editing across layers.

## Privacy Posture

- Local-only by default.
- No push to GitHub servers.
- Keep account data, SQL dumps, IPs, and client state private.

## Preferred Outcome

The project should feel like a living operating workspace:

- clear memory,
- clear handoff,
- clear module boundaries,
- clear diagnostics,
- clear workflows,
- and enough automation to keep future work grounded in current state.
