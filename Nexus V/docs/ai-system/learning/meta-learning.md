# Meta-Learning

Meta-learning is learning how to improve the project learning process.

## Questions

- Which failures repeat?
- Which docs are ignored?
- Which scans produce noise?
- Which work items become stale?
- Which assumptions keep reappearing?
- Which tools should exist because the task repeats?

## Meta-Learning Actions

- improve read order,
- improve scanner precision,
- add or remove playbooks,
- promote repeated facts into core memory,
- move low-use facts into deep archive,
- add better verification gates.

## Review Cadence

After every major milestone:

1. Review bugs.
2. Review decisions.
3. Review stale work.
4. Review scan signals.
5. Update this system.
