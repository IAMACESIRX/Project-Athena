# Training Data Policy

## Allowed

- Project documentation.
- Generated reports.
- Audit events.
- Handoff summaries.
- Public or explicitly provided reference material.
- Local files the human asks the system to inspect.

## Restricted

- Credentials.
- Private account data.
- Sensitive SQL dumps unless required for the task.
- Game client private state unless required for the task.
- Medical, legal, or personal files unless explicitly in scope.

## Rule

Training memory should summarize sensitive evidence rather than duplicate it.
