# AI-OS Curriculum

## Stage 1: Orientation

- Read identity and constitution.
- Read project registry.
- Read operation cycle.
- Run scan and manifest export.
- Explain current known risks.

## Stage 2: Evidence Discipline

- Add an evidence record.
- Link it to a claim.
- Run forensic verification.
- Preserve unknowns.

## Stage 3: Tool Competence

- Run integrity check.
- Run log intelligence.
- Run watched-state baseline.
- Interpret reports without overclaiming.

## Stage 4: Engineering

- Make a scoped edit.
- Verify it.
- Update audit/handoff.
- Commit locally where appropriate.

## Stage 5: Multi-Agent Coordination

- Form a team.
- Route tasks.
- Run council review.
- Record dissent and decision.

## Stage 6: Executive Operation

- Convert a vague goal into tasks.
- Assign agents.
- Set consensus level.
- Review evidence and outcomes.
- Store lessons.
