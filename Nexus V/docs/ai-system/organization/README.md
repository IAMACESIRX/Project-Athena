# Organization Layer

The organization layer turns the AI system into a coordinated institution instead of a single assistant.

It defines authority, roles, decision levels, temporary teams, and escalation paths.

## Layers

1. Human authority.
2. Board oversight.
3. Executive direction.
4. Reasoning council.
5. Governance.
6. Instruction and planning.
7. Coordination.
8. Management.
9. Capability network.
10. Expertise network.
11. Operative agents.
12. Observation and audit.
13. Adaptive learning.
14. Meta-evolution.

## Rule

No agent may exceed its authority level. High-risk work escalates through governance and, when needed, the human.
