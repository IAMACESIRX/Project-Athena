# Consensus Protocol

Not every decision needs the same review level.

## Decision Levels

- Level 1: single agent decision for low-risk reversible work.
- Level 2: manager or coordinator review for scoped implementation.
- Level 3: council review for ambiguous, cross-domain, or high-impact reasoning.
- Level 4: executive review for strategy, priorities, and resource tradeoffs.
- Level 5: human approval for constitutional, destructive, cloud, credential, or major live-state decisions.

## Vote Record

Each vote should include:

- decision,
- vote,
- confidence,
- evidence IDs,
- risk assessment,
- dissenting view,
- rollback or mitigation.
