# Project Continuity

## Durable Narrative

This project began as a layered local backup stack for:

- a full WoW client backup,
- server live-state SQL dumps,
- and a WoW server project containing assistant scaffolding plus AzerothCore source trees.

The human wants this to become a living local project operating system that can support many AIs and humans over time.

## Repeated User Intent

- Local-only unless explicitly changed.
- Strong memory and context continuity.
- Granular control over client, server, live-state, and AI tooling.
- Ability to reverse mistakes.
- Ability to diagnose live runtime.
- Ability to add, remove, and understand modules.
- Strong audit, causality, and decision tracking.
