# API Contracts

Future runtime APIs should expose:

- `GET /identity`
- `GET /constitution`
- `GET /projects`
- `GET /projects/{id}`
- `GET /agents`
- `POST /tasks`
- `GET /tasks/{id}`
- `POST /messages`
- `POST /operation-cycle/run`
- `GET /operation-cycle/latest`
- `POST /evidence`
- `POST /claims`
- `POST /audit-events`

Until runtime services exist, the file paths in `system-manifest.json` are the API.
