# A.E.S.I.R. AIO Adapter

A.E.S.I.R. does not maintain independent pairwise contracts. It reads and writes the shared contract defined by `contracts/AIO-MASTER-CONTRACT.yml`.

A.E.S.I.R. owns epistemic partitioning, the full scientific method, intra- and cross-scientific integration, multiscale analysis and polymath expansion. Any A.E.S.I.R.–specific contract view must be generated from the current AIO instance with `tools/aio_contract.py view`; it is non-authoritative and must preserve the instance hash and lineage.
