# AIO Unified Full-Stack Pipeline

## Prime rule

**Input once; process through the entire system.** Every idea traverses the same contract instance through scientific, intrascientific, polymath, systems, synthesis, engineering, simulation, mitigation, governance, attestation and execution passes.

Weights control how deeply each pass runs. No pass is silently removed.

## Ordered weave

1. Capture objective, meaning, authority and constraints.
2. Gate privacy, safety and permissions.
3. Map present and historical state.
4. Separate facts, observations, assumptions, hypotheses, speculation, contradictions and unknowns.
5. Run the full scientific method.
6. Apply discipline-specific methods, map shared variables and resolve cross-scientific contradictions.
7. Sweep every scale from physical law and materials to civilisation and time.
8. Expand evidence, hypotheses and candidate space through A.E.S.I.R.
9. Build the dependency and interaction hypergraph.
10. Generate and symmetrically challenge the candidate lattice through F.O.R.G.E.
11. Rank candidates and mine the mechanisms that make them work.
12. Reverse-reconstruct a native architecture rather than bolting donors together.
13. Run the full engineering lifecycle: requirements, interfaces, budgets, failure modes, prototyping, verification, operations and recovery.
14. Move avoidable complexity upstream into compilers/toolchains and simplify the usable result.
15. Close the loop through simulation, prototypes, measurement and reality writeback.
16. Offset weaknesses while explicitly preserving benefits and exposing new costs.
17. Apply ATHENA governance, memory, promotion and continuity controls.
18. Apply Aegis trust, attestation and commit decisions.
19. Materialise the authorised state through Nexus‑V branch/diff/commit/snapshot/rollback semantics.
20. Produce human, AI, script and hardware views from the same state.
21. Re-evaluate the method and register future revalidation triggers.

## Manual and machine equivalence

A person may complete every phase directly in JSON/YAML or a rendered Markdown view. AI, scripts and programs update the same fields and append the same event records. Manual edits and interventions are first-class state transitions, not exceptions.
