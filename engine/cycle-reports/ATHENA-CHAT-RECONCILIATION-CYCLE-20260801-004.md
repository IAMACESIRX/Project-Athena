## Decision Pass

Problem:
: Important architecture intent existed only in chats, while several generated
  images and attachments remained unavailable.

Known:
: Linear text retrieval passed a second comparison; distributed docking,
  Operative Duplex, Lightcore, sensor fusion, Material Behavioral Atlas, and
  Reality Compiler concepts were incompletely represented in canonical files.

Assumed:
: Project-relevant architecture should be promoted with source and maturity
  labels, while unrelated personal memory should remain outside the repo.

Unknown:
: Completeness of alternate/deleted chat branches, missing binary outputs,
  original generated deep-dive files, and feasibility of experimental device
  concepts.

Chosen action:
: Add a source register and focused specifications, connect them to first-read
  and capability paths, add machine-readable adapter/capsule/action contracts,
  and create a pending-asset intake ledger.

Why:
: This preserves the recoverable knowledge now without turning conversation
  brainstorming into unsupported factual or implementation claims.
