# Full Reasoning Chain Checklist

Use this when the task is complex, risky, ambiguous, multi-module, or likely to survive across AI handoffs.

## Identity

- Human request restated.
- Active layer named.
- Success condition named.
- Non-negotiable constraints named.
- Sensitive files identified.

## Evidence

- Direct observations listed.
- Inferences labeled.
- Assumptions labeled.
- Unknowns listed.
- Contradictions listed.
- Evidence IDs linked when available.

## Reasoning Pass

- Who is affected?
- What exists?
- When did it change?
- Where is it located?
- Why might it be happening?
- How can it be tested?
- What outcome do we want?
- What conditions must exist for that outcome?
- What evidence would falsify the current idea?
- What second-order effects might appear?

## Cognition Systems

- Anti-hallucination gate applied.
- Fuzzy truth state assigned where needed.
- Superposition preserved for unresolved interpretations.
- Algorithmic inversion run from desired result backward.
- Retrocausal reconstruction run from later symptoms to earlier causes.
- Non-monotonic revision checked against new evidence.
- Hypergraph relationships identified.
- Semantic compression prepared for handoff.

## Decision

- Proposed action is scoped.
- Rollback path is known.
- Verification command is known.
- Audit or work item update is planned.

## Closure

- Verification result recorded.
- Claims/evidence/timeline updated if facts changed.
- Handoff updated if context matters.
- Git status checked.
- Local-only push rule preserved.
