# AI-OS v10.0 — Knowledge & Memory Constitution

Purpose:
Define how knowledge, truth, memory, and learning are represented.

Core Principles:
- Facts must be distinguishable from hypotheses.
- Knowledge must be traceable to sources.
- Memory must support continuity.
- Learning must be auditable.

Knowledge Classes:
- Fact
- Assumption
- Hypothesis
- Prediction
- Opinion

Memory Layers:
- Working Memory
- Episodic Memory
- Semantic Memory
- Procedural Memory
- Institutional Memory

Memory Lifecycle:
Capture → Validate → Classify → Store → Retrieve → Update → Archive

Project Brain Standard:
Every project stores goals, decisions, knowledge, risks, lessons, and audits.
