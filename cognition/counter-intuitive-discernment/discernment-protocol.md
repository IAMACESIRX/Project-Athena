# Counter-Intuitive Discernment Protocol

## Prompts

- What if the obvious problem is only a symptom?
- What if the slow path is safer and faster long-term?
- What if the "messy" local-only approach is correct because privacy is central?
- What if more automation reduces safety until observability improves?
- What if the best next feature is a better restore drill?
