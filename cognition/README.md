# Cognition Systems

This folder contains advanced reasoning engines for the AI operating system.

These systems are not excuses for unsupported claims. They are disciplined ways to explore hidden structure, generate new hypotheses, challenge assumptions, coordinate group reasoning, and then bind outputs back to evidence.

## Systems

- `subtext/`: infer unstated intent, constraints, emotion, and implication while labeling uncertainty.
- `correlation/`: detect relationships between events, files, changes, bugs, and outcomes.
- `collaborative-group-dynamics/`: model team roles, coordination, conflict, and shared decisions.
- `anti-hallucination/`: prevent unsupported claims and force evidence labels.
- `conceptual-leap/`: generate bold hypotheses with guardrails.
- `self-generated-paradigms/`: create and test new mental models.
- `counter-intuitive-discernment/`: consider unlikely but high-value interpretations.
- `socratic-deconstruction/`: break assumptions through structured questioning.
- `non-linear-disruption/`: escape local optima and stale workflows.
- `original-creation/`: produce new designs, features, and systems while preserving auditability.
- `dynamic-process-plasticity/`: update process behavior based on feedback and evidence.
- `liquid-state-machine/`: maintain a dynamic reservoir of signals and transient context for readout.
- `algorithmic-inversion/`: think backward from desired outcomes or observed effects.
- `semantic-compression/`: compress large context while preserving decisions, evidence, and causality.
- `multi-valued-fuzzy-logic/`: reason with partial, uncertain, stale, and contradicted truth states.
- `semantic-drift-self-correction/`: detect and correct concepts whose meanings drift.
- `superposition-nonbinary/`: keep multiple possible states alive until evidence collapses them.
- `retrocausal-processing/`: reconstruct earlier causes from later observations.
- `non-monotonic-reasoning/`: revise conclusions when new evidence arrives.
- `contextual-anchoring/`: maintain stable anchors that prevent context drift.
- `hypergraph-relational-processing/`: model many-way relationships and dependencies.

## Core Rule

Creative and inferential systems produce candidates. Truth systems decide what is supported.

Every output should be labeled:

- verified,
- plausible,
- speculative,
- contradicted,
- needs test.
