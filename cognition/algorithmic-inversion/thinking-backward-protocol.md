# Thinking Backward Protocol

## Method

1. State the target outcome or observed effect.
2. Ask what must be true immediately before it.
3. Repeat backward until reaching known current state.
4. Mark each backward step as verified, plausible, speculative, or contradicted.
5. Convert the path into a forward test or action plan.

## Output

```text
Target:
Known current state:
Backward chain:
Required conditions:
Unknowns:
Forward verification:
Rollback:
```

## Guardrail

Do not confuse a valid backward chain with proof that the chain actually happened.
