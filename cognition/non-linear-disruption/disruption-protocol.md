# Non-Linear Disruption Protocol

## Disruption Moves

- change the scale,
- change the layer,
- invert the goal,
- remove a constraint,
- add a safety constraint,
- solve with a map instead of code,
- solve with a tool instead of manual work,
- solve with a policy instead of repeated judgment,
- delay automation until observability exists.

## Process

1. State current path.
2. Identify why it may be stuck.
3. Generate three non-linear alternatives.
4. Safety-check each alternative.
5. Pick a reversible experiment.
