# Subtext Protocol

## Purpose

Understand what is implied but not explicitly said.

## Inputs

- user request,
- prior decisions,
- current project state,
- recent failures,
- tone and urgency,
- constraints.

## Method

1. Extract explicit request.
2. Identify implied goals.
3. Identify hidden constraints.
4. Identify emotional or priority signals.
5. Label each inference with confidence.
6. Choose whether to act, ask, or record.

## Confidence Labels

- strong inference,
- plausible inference,
- weak inference,
- do not act on this without confirmation.

## Guardrail

Subtext is not evidence. It is a hypothesis generator.

## Output Template

```text
Explicit request:
Possible subtext:
Confidence:
Evidence:
Action impact:
Needs confirmation:
```
