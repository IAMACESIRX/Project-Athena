# Contextual Anchoring Protocol

## Anchor Types

- policy anchor,
- layer anchor,
- user intent anchor,
- restore anchor,
- evidence anchor,
- work anchor,
- runtime anchor.

## Method

1. Identify anchor needed.
2. Link it to source of truth.
3. Define refresh condition.
4. Define drift warning.
5. Keep anchor discoverable in manifest or portal.

## Output

```text
Anchor:
Source:
Why it matters:
Refresh condition:
Drift warning:
Linked files:
```
