# Original Creation Protocol

## Creation Loop

1. Frame need.
2. Generate candidate concepts.
3. Combine unrelated useful patterns.
4. Add constraints.
5. Make it modular.
6. Make it testable.
7. Make it reversible.
8. Record why it exists.

## Novelty Checks

- Is this solving a real problem?
- Is it simpler than repeated manual work?
- Does it connect to existing registries?
- Does it create useful future capability?
- Can it fail safely?
