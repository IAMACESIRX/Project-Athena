# Cognition Output Labels

Use these labels on all outputs from advanced cognition systems.

## Labels

### Verified

Direct evidence supports the claim.

### Plausible

Evidence points toward the claim, but it is not fully confirmed.

### Speculative

Useful idea, weak evidence. Must not be treated as fact.

### Contradicted

Evidence conflicts with the claim.

### Needs Test

Potentially useful, but requires experiment or observation.

## Rule

Do not let speculative cognition update core memory as fact. It may enter research, counterfactuals, council notes, or work items.
