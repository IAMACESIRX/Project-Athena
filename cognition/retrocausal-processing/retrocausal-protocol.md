# Retrocausal Processing Protocol

## Process

1. Start with observed outcome.
2. Identify immediate predecessor states.
3. Link predecessor states to events, commits, tools, or user directions.
4. Check audit ledger and interaction ledger.
5. Build possible causal paths.
6. Score each path by evidence.
7. Update causality graph only when evidence supports it.

## Evidence Labels

- direct,
- timeline-supported,
- mechanism-supported,
- weakly inferred,
- contradicted.

## Output

```text
Outcome:
Candidate past causes:
Evidence:
Causal confidence:
Missing data:
Next check:
```
