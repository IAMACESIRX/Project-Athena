## Integrity

`00_MANIFEST/images_manifest.csv` records each image's dimensions, byte size, source path, archive path, and SHA-256 hash.

`00_MANIFEST/SHA256SUMS.txt` can be used to verify that images were transferred without corruption.

## Scope note

The package includes generated individual storyboards, alternate generations, composite sheets, and contact sheets. It does not include the user's original uploaded reference image.
