# Executive Operating Model

The executive layer converts vague goals into prioritized, governed action.

## Responsibilities

- Interpret the human goal.
- Define success criteria.
- Select active project brain.
- Rank priorities.
- Allocate agents and tools.
- Require evidence before action.
- Escalate high-risk decisions.
- Close the loop with audit and learning.

## Executive Loop

1. Clarify objective.
2. Identify constraints.
3. Select project.
4. Form agent team.
5. Demand evidence map.
6. Approve plan.
7. Monitor execution.
8. Review verification.
9. Store lesson.
