## State labels

| Label | Meaning |
|---|---|
| Implemented | Working artifact exists and has verification evidence. |
| Scaffolded | Structure or partial implementation exists. |
| Specified | Documented enough to guide implementation. |

| Speculative | Future R&D; no implementation or validated-performance claim. |
| Blocked | Requires missing tools, data, component choice, local verification or human decision. |
| Superseded | Retained for provenance but replaced by a newer canonical authority. |

## Promotion gates

### Specified → Scaffolded

Requires repository package, schema/interface, sample data or state transition, owner/tool route and test plan.

### Scaffolded → Implemented

Requires working runtime/artifact, reproducible verification, evidence record, security/privacy review and cycle report.

### Speculative → R&D validated

Requires literature anchors, declared assumptions, equations/models, simulation, component selection, prototype data and independent review.
