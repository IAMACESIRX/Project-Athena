## Mirror discipline

1. GitHub files define canonical wording.
2. Notion mirrors subsystem state, labels and navigation.
3. Asana tracks work but cannot redefine architecture.
4. Google Drive stores distribution copies and review dossiers.
5. Figma/Canva contain editable design outputs but must cite the canonical repo.
6. Consensus/SciSpace support specific primitives and limitations, not proof of the complete systems.
7. Local ATHENA/RTL/toolchain results must be sanitized before cloud publication.
8. Every mirror shows a last-synchronized date and outstanding validation state.
