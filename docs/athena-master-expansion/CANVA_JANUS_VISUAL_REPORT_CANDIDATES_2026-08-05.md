## Promotion workflow

A candidate becomes a controlled Canva mirror only after:

1. The user selects the preferred candidate.
2. The candidate is converted to a permanent editable Canva design.
3. Page-by-page terminology is checked against the canonical repository.
4. Any generated inaccuracies, unreadable text or ownership mistakes are corrected.
5. The permanent Canva design ID and edit/view URL are added to this register.
6. The plugin mirror index and sync log are updated.
7. The final design is labelled with its last synchronization date and validation status.
