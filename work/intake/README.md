# Athena Intake Packets

This folder stores task-intake packets for non-trivial Athena runs.

Use `templates/athena-task-intake.md` for markdown intake records and
`schemas/athena-task-intake.schema.json` for machine-checkable intake data.

Naming:

`ATHENA-INTAKE-YYYYMMDD-NNN-short-title.md`

Each packet should state the human goal, active layer, priority source, files
read, known facts, assumptions, unknowns, risks, required output, verification
method, and memory writeback targets.
