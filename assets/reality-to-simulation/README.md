# Reality-to-Simulation Engineering Assets

This directory is the canonical index for prototype and visualization artifacts associated with R2S-MSP.

## Committed lightweight sources

- Controlled architecture/specification documents under `docs/athena-master-expansion/`.
- Machine-readable observation, KBM and OASIS physical-twin schemas.
- Controlled vector SVG system diagrams.
- Rev-B BOM, module register and 1:1 front-plate DXF are staged for source-level publication.

## Canva visualization sources

- [`canva/red-phosphor-camera-report/`](canva/red-phosphor-camera-report/) — 14-page Project Athena red-phosphor multisensor camera engineering report, including the editable/view-only Canva source links, machine-readable metadata, portable viewer and controlled content snapshot.

The live Canva design is the authoritative visual source. GitHub remains authoritative for engineering definitions, schemas, requirements, validation status and release lineage.

## Binary artifact mirror

The full Rev-B package contains:

- `multisensor_ai_fusion_system_diagram.png`;
- `ATHENA_R2S_RevB_Fabrication_Drawing_Set.pdf`;
- `ATHENA_R2S_RevB_Scaled_Assembly.glb`;
- `ATHENA_R2S_RevB_Production_Blueprint_Bundle.zip`.

These are mirrored through the Project Athena Google Drive artifact workspace when connector upload permits. GitHub remains canonical for definitions, status, schemas and release lineage; Drive is the portable binary mirror.

Do not fabricate or operate active UV, laser, RF or THz systems without specialist safety, regulatory and engineering review. The Rev-B package is a prototype integration baseline, not a certified production release.
