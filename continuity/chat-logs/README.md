# Chat Logs

Store chat records here.

Suggested naming:

`chat-YYYYMMDD-HHMMSS-source-title.md`

## Classes

- raw: close to transcript, may be long.
- summary: compressed session record.
- decision: chat excerpt that produced a decision.
- incident: chat excerpt tied to a failure or correction.

## Privacy

Chat logs may contain personal or sensitive project details. Keep local.
